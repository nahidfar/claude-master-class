# Private source documents

Attach your own redacted resume PDF or project document to an approved AI workspace.
If file attachments are unavailable, paste redacted text.

This folder is an optional local holding area. All other files in it are ignored
by Git. Never move source documents into public assets or import them into app code.
Ignoring files is not encryption and does not remove files already committed.

Only verified facts that you choose to make public belong in `data/profile.json`.
The website itself does not implement file uploads or PDF extraction.
